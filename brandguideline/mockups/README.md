# Brand Book Mockups Specification — ES Clinical Research

Place high-resolution `.png` files directly into this directory (`/brandbook/mockups/`).
The brand book dynamically attempts to load each image file. If the file is not yet available, a calibrated, proportional placeholder block (`#111`) is rendered with the exact aspect ratio and dimensions labeled.

## Technical Guidelines
- Color Space: sRGB for digital mockups, CMYK preview exports converted to sRGB PNG.
- Background: Flat, orthographic, device-frame-free, no heavy drop shadows.
